vLLM只读取本地固定revision的Qwen3-0.6B。本轮8个文件已准备，权重大小与官方LFS SHA256核对记录在 `model-verified.json`，文件清单为 `model-download.json`。新机器可用项目Python重建并核对权重；以下网络命令经用户授权代理运行：

```bash
.venv-cpu/bin/python scripts/with_proxy.py -- .venv-cpu/bin/python - <<'PY'
import hashlib, json, shutil
from pathlib import Path
from urllib.request import urlopen
revision = 'c1899de289a04d12100db370d81485cdf75e47ca'
folder = Path('models/Qwen3-0.6B') / revision
folder.mkdir(parents=True, exist_ok=True)
records = []
for name in 'config.json generation_config.json merges.txt tokenizer.json tokenizer_config.json vocab.json model.safetensors LICENSE'.split():
    target = folder / name
    if not target.exists():
        partial = folder / (name + '.partial')
        with urlopen(f'https://huggingface.co/Qwen/Qwen3-0.6B/resolve/{revision}/{name}', timeout=120) as response, partial.open('wb') as stream:
            shutil.copyfileobj(response, stream, length=1024*1024)
        partial.replace(target)
    with target.open('rb') as stream:
        digest = hashlib.file_digest(stream, 'sha256').hexdigest()
    if name == 'model.safetensors' and digest != 'f47f71177f32bcd101b7573ec9171e6a57f4f4d31148d38e382306f42996874b':
        raise RuntimeError('Model SHA256 mismatch; stop before GPU execution')
    records.append({'filename': name, 'bytes': target.stat().st_size, 'sha256': digest})
with Path('logs/my-model-download.json').open('x') as output:
    json.dump({'revision': revision, 'files': records}, output, indent=2)
PY
```

## 常见失败与恢复

- `ModuleNotFoundError: procure_rl`：从项目根执行，带 `PYTHONPATH=src`。
- 输出目录存在：换新目录；S0无checkpoint，无需恢复训练状态。
- 缓存写到只读home：每条uv指定项目 `UV_CACHE_DIR / UV_PYTHON_INSTALL_DIR`，模型/编译器缓存同样写项目。
- NVML权限失败：保留失败，区分执行上下文与主机事实；只读主机访问和计算授权分开。
- `Building source distributions ... disabled`：审阅固定构建配置并记录允许范围，不放开全部CUDA扩展源码。
- 普通包在Torch索引找不到：检查来源策略；核心CUDA wheel用明确URL，其他包用PyPI，不擅自换版本。
- 解析成功但导入失败：保存traceback，核对实际传递依赖与API；修正后完整保存新解析/安装/导入记录。
- FlashAttention二进制导入/符号失败：核对CPython/Torch/CUDA家族/CXX11 ABI与wheel，不能自动转系统nvcc源码编译。
- Triton找不到编译器或libcuda：核对项目 `.venv-toolchain`、包装器和driver-only链接；禁止回落系统GCC/Toolkit。
- vLLM显存不足：先退出本项目探针并保留失败，只在已获准5/7内重新检查当时容量，不处理其他用户进程、不扩展设备集合。
- 超时：报告保留部分stdout/stderr与未知计算状态，确认本次子进程已退出，再用新目录重试；超时绝不能标通过。
- 网络失败：可用授权的单命令proxy包装，保留代理前后的错误；网络报错不等于依赖不兼容。
