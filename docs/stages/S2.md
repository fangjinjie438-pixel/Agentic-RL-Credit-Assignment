官方在本次核验时把该别名映射到 `DeepSeek-V4.1-Flash-1017`；它不是不可变 revision。API 返回的 model、请求日期、原始响应、usage 与缓存分别保存，实际不可变 model_revision 未知时为 null。选择依据、价格及原始网页证据见 [来源与教师审计](../s2-source-audit.md)。

密钥独立放在项目 **`.secrets/deepseek_api_key`**，内容为单个有效 key；该目录已 gitignore，不进入配置/日志/源码哈希。也可将 `key_file` 改成 `env_var: "DEEPSEEK_API_KEY"`（两种来源选一个）。当前文件不存在，实际凭据检查已记录 blocked，**外部教师请求 0、真实专家成功轨迹 0、账单金额未知**。

## 数据来源与边界

真实来源为 Amazon Reviews 2023 Electronics，固定 HF revision `2b6d039ed471f2ba5fd2acb718bf33b0a7e5598e`。从 Parquet 首 row group 只读所需列，实传 **1,222,800 bytes**，解出 1,000 条记录后保留 12 条原字段摘录。没有下载整片/完整官方商品库，LFS 全文件 SHA 未本地核验；逐 Range 的实际字节/SHA 和原始选定列 JSON 的哈希另存。采集时历史 USD 价格不代表当前报价。

`sources.normalize_records` 逐条核对 raw SHA、原字段路径、原句、币种、数值与单位，Decimal 统一质量单位至 g、功率至 W；缺价格、冲突、模糊单位拒收，不根据标题猜规格。12 条均有价格/重量，8 条有可信颜色。品牌从原字段取，家族暂按整品牌保守聚类并标记人工待确认。

官方 benchmark 只访问目标商品元数据生成排除表，662 任务得到 660 个唯一 ID、660 标题、558 整品牌保守家族、420 品牌型号。659 条目标有结构化 Brand，3 条缺品牌仍待审，`metadata_complete=false`。四条 pilot 商品因 Logitech/Samsung/Dell/HP 品牌重合被 quarantine；剩余 exact-ID 重叠为 0。官方 query/persona/rubric 不进入构建、奖励或模型选择。原 ID-only 索引及其旧运行保留为历史证据，最终索引不据此声称完整近家族覆盖。

代码 MIT 与数据原始研究用途条款分开记录，不能将 MIT 应用到商品内容。12 条真实摘录和 S1 虚构工程夹具为两个显式模式；后者始终 `engineering_only`，不导出成专家训练数据。

## 流水线与产物

逐文件用途/API 见 [data README](../../src/procure_rl/data/README.md)。执行顺序如下：

1. 固定来源 → 验字段/原句/单位 → 无 split 的事实与证据。
2. family、brand-model、显式近重复组、规范标题哈希、MinHash 候选与精确 Jaccard 连通簇 → 整簇固定 seed 划分；命中已提供官方排除信息的整簇 quarantine。
3. 先求完整检索 split 的全部合法解，再渲染英文 query/persona/澄清。base/反事实/改写用显式 root/parent/pair ID，兄弟始终同 split。默认构建器不自动做教师表达增强，数量记录为 0；`apply_expression_rewrite` 提供事实不变的 prose-only 改写入口，仍需审核。
4. 反事实只改一个约束值，重算非空合法集；本版要求两侧合法集不相交，明确要求决策改变。找不到时记拒收原因，不把纯改写当反事实。
5. token 余弦与受控同义词检索只产语义审核候选，**不是 8B 复核通过**；同时生成至少 200 条人工抽检要求、全部分歧样本和家族待审队列。pilot 不足 200 时记录实际可审数量。
6. 采集器只发送 reset/schema/实际 observation。工具真实执行；不发送私有任务、合法解 ID、快照、奖励或终局诊断。默认需显式选 engineering/API/cache-only 模式。
7. 新会话真实逐步回放，对 observation、事件、奖励、公共对话、任务/库/策略/最终状态哈希比对；成功且证据完整才接收。工程脚本即使接收也 `expert_eligible=false`；失败原因保留。
8. `s2-audit` 重新回放，并导入 hash 绑定的人工/独立模型审核记录，输出发布门槛；当前均 withheld。没有仅凭日志成功字符串或修改 reward 字段接受轨迹的路径。

split 用物理独立只读 SQLite。`load_tasks` 默认仅 train/dev，sealed_test 必须显式 `include_sealed_test=True`；采集迭代器只选 train，禁止封存/官方任务进入教师采集。S1 Catalog 保留原真实 brand/store，旧工程数据仍使用 family 兜底。

## CPU 开发与学校 Linux 命令

普通流水线与测试只用项目 `.venv-cpu` 和标准库，无大模型或教师依赖。从项目根目录运行，每次选新输出目录：

```bash
PYTHONPATH=src .venv-cpu/bin/python -m procure_rl s2-build --config configs/s2.json --output logs/my-s2-build
PYTHONPATH=src .venv-cpu/bin/python -m procure_rl s2-collect --config configs/s2.json --dataset logs/my-s2-build/dataset --output logs/my-s2-engineering --engineering --limit 2
PYTHONPATH=src .venv-cpu/bin/python -m procure_rl s2-audit --dataset logs/my-s2-build/dataset --collection logs/my-s2-engineering --output logs/my-s2-audit
PYTHONPATH=src .venv-cpu/bin/python scripts/run_cpu_tests.py --stage S2 --config configs/s2.json --output logs/my-s2-tests
```

预期构建/工程采集/门槛审计退出 0；审计成功只表示门槛已计算，`ready_for_formal_training=false` 仍阻止发布。全量测试包括临时 loopback HTTP server，需要执行上下文允许本机临时 socket；不访问外部教师。项目解释器不得替换为系统 Python/Toolkit/GCC。

来源重新获取的已验证命令、固定 revision、只读代理和 CPU PyArrow 使用方法见 [scripts/data](../../scripts/data/README.md)。只有一次性 Parquet 解析使用 `.venv-gpu` 已装 PyArrow，`CUDA_VISIBLE_DEVICES=''`，无 Torch/vLLM 导入与 CUDA 上下文；普通离线执行不依赖该包。

有效密钥就绪后，用相同不可变 dataset 执行真实教师（本轮凭据检查已执行，但没有外部传输）：

```bash
PYTHONPATH=src .venv-cpu/bin/python -m procure_rl s2-collect --config configs/s2.json --teacher-config configs/s2-teacher.json --dataset logs/my-s2-build/dataset --output logs/my-s2-teacher --cache-directory .cache/s2-teacher --execute-api --limit 2
```

`--cache-only` 替代 `--execute-api` 时只消费已完成且请求/策略/提示哈希相符的缓存。未完成或计费不确定的请求不自动重发；完成缓存可用于从新输出目录恢复公共对话。费用是配置价×provider usage 的估算，`billed_cost_usd` 保持 null，缺 usage 也不填 0。

人工审核决策另存新文件，不修改不可变数据包中的队列。文件可含 `human_reviews/identity_reviews/independent_reviews` 数组：人工项提供 task_id/task_sha256、role=human、reviewer、reviewed_at、decision；家族项另提供 product_id/product_sha256/family；独立模型项含 task_id/task_sha256、status=completed、decision 和实际 model_revision。人工拒收/冲突阻止发布，模型拒收须有真实人工 accept 裁决并标记 `adjudicates_model_disagreement=true`。过期/不匹配记录拒收。将文件传给 `s2-audit --reviews 路径`，不编写虚构同意记录。

构建保存源/配置/数据/库哈希、manifest、三 split tasks、quarantine、拒收、语义与人工队列。采集保存原请求/原始响应、日期、模型标识、usage、估算费用、公共消息、episode、accept/reject ledger、expert-candidates 与 release-gate。尚无 tokenizer/监督 token/checkpoint；S3 的 action-only 转换未实现。

## 常见失败与恢复

输出目录已存在时换目录，不覆盖证据。原始来源、单位或哈希失败时保留 rejected，不回落猜测值；临时源码/候选描述不能作为锁或事实。缺 FTS5 真实报错，不能返回空结果冒充通过。dataset manifest 任一文件哈希改变会拒绝采集，修改来源/模板/排除规则后重建新 revision。

教师缺密钥在网络发送前停止并写 blocked；HTTP失败保留脱敏原响应和 billing_uncertain，不自动重试。已有全局代理时，loopback测试明确绕过代理；外部代理沿用用户授权配置。源抓取和教师本地HTTP的早期失败记录保留，精确时间未记录时不倒填。
